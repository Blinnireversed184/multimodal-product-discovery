## 🎯 What Is This?

multimodal-product-discovery is a smart search tool that lets you find products using **pictures, text, or both together**. Instead of typing exact keywords, you can upload a photo of a product you like, type a vague description, or combine both—and the app instantly finds the most relevant items from your catalog.

Think of it like Google Images, but specifically for your product inventory. It understands what's in a picture and matches it to the right products, then ranks them so the best matches appear first.

---

## ✨ Key Features

### 🖼️ Search with Images
Upload any product photo. The system analyzes the image's colors, shapes, patterns, and visual features to find similar items in your database.

### ⌨️ Search with Text
Type natural language descriptions like "red running shoes under $50" or "wooden coffee table with metal legs." The system understands meaning, not just keywords.

### 🔄 Combined Search
Use both a picture and a text description together for ultra-precise results. For example, upload a photo of a blue dress and type "size M" to narrow it down.

### 🏆 Personalized Ranking
The app learns from your preferences and reorders results to show you what you're most likely to buy first. Over time, it gets smarter about what you like.

### ⚡ Lightning Fast
Results appear in under a second, even with thousands of products. No more waiting for slow searches.

### 📊 Works with Your Data
The system connects to your existing product database and indexes everything automatically. No manual tagging or data entry required.

## 🛟 Troubleshooting

### Issue: Application Won't Start
- Make sure you have Windows 10 or later
- Check that you have at least 4 GB of RAM free
- Try running the app as administrator (right-click → Run as administrator)

### Issue: Search Results Are Slow
- Close other heavy applications running in the background
- Ensure you have a stable internet connection
- Restart the application to clear cached data

### Issue: Images Won't Upload
- Use common image formats like JPG, PNG, or GIF
- Keep image file sizes under 10 MB
- Ensure the image is a clear, well-lit product photo

## 📊 Technical Overview (For Curious Minds)

This project combines several powerful technologies:

- **CLIP**: An AI model that understands both images and text
- **FAISS**: A library for fast similarity searching
- **Spring Boot**: Handles the backend server logic
- **FastAPI**: Provides the machine learning API endpoints
- **PostgreSQL**: Stores all product data securely

The architecture is designed to be scalable, reliable, and fast—ready for production use.
